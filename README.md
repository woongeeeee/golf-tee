# ⛳ 전국 골프장 티타임 통합검색 (GOLF TEE)

티스캐너 실데이터로 전국 골프장의 실시간 티타임·최저가·캐디 정보를 보여주는 Streamlit 앱.
왼쪽 **👤 티스캐너 로그인**에서 본인 티스캐너 아이디(전화번호)+비밀번호로 로그인해 사용하세요.

- 📋 전국 최저가: 전체 골프장을 훑어 실제 최저가 계산
- 🌏 전국 전체 골프장 / 🔍 이름 검색
- 🗺️ 지도 · ☀️ 날씨(Open-Meteo)

로컬 실행: `pip install -r requirements.txt` 후 `streamlit run app.py`
